# HanaPlay Android

HanaPlay is an Android and Google TV client for Plex and Silo.

Download APKs from [GitHub Releases](https://github.com/ManavA/hanaplay-android/releases). Releases include a SHA256SUMS.txt file for checking downloads.

Download the APK, open it on your device, and follow Android’s installation prompts. Android may ask you to allow installation from the app used to open the APK. Version 9.07 requires Android 9 or later and includes arm64-v8a, armeabi-v7a, and x86_64 binaries.

Source code availability is TBD pending licensing review. This repository distributes release binaries and contains no application source code.
